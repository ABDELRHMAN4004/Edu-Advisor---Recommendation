1. WHAT DOES THIS FUNCTION DO?
Attempts to read numeric course grades from a text-based transcript.

2. WHY DOES THE PROJECT NEED IT?
Looks for catalog course codes and nearby percentages or numbers; keeps a grade only when there is one plausible candidate.

page_texts, catalog_course_ids

The function receives the values listed above. 'self' means the current
EduAdvisor object, which contains the course catalog and academic rules.
Optional arguments use their default values if the caller leaves them out.
