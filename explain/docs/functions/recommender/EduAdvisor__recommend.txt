1. WHAT DOES THIS FUNCTION DO?
Builds the final set of recommended courses for a student.

2. WHY DOES THE PROJECT NEED IT?
Chooses the GPA source, scans available courses, filters by specialization and eligibility, scores candidates, sorts them, includes mandatory retakes, fills remaining credit capacity, and builds the response.

3. INPUTS / PARAMETERS
self, student: StudentInput, max_credits: int, min_credits: int, top_n: int, current_semester: int

The function receives the values listed above. 'self' means the current
EduAdvisor object, which contains the course catalog and academic rules.
Optional arguments use their default values if the caller leaves them out.
