1. WHAT DOES THIS FUNCTION DO?
Calculates the internal priority score for one eligible course.

2. WHY DOES THE PROJECT NEED IT?
Adds or subtracts points for retakes, course type, student level, GPA, future-course unlocks, credits, graduation progress, and curriculum requirements.

3. INPUTS / PARAMETERS
self, course_id: str, student: StudentInput, passed: Set[str]

The function receives the values listed above. 'self' means the current
EduAdvisor object, which contains the course catalog and academic rules.
Optional arguments use their default values if the caller leaves them out.
